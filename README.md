# 📊 Dashboard de Vendas (Relatório Gerencial)

Dashboard interativo desenvolvido para análise gerencial de vendas de eletrônicos, construído com tecnologias web modernas e integrado com planilhas do Excel.

---

## 🚀 Tecnologias Utilizadas

* **HTML5** - Estruturação das páginas e componentes visuais.
* **CSS3** - Estilização responsiva, layout em Grid/Flexbox e design limpo.
* **JavaScript (ES6+)** - Lógica de manipulação de dados, filtros dinâmicos e manipulação do DOM.
* **SheetJS (xlsx)** - Biblioteca para leitura e processamento de arquivos do Excel no navegador.
* **Chart.js**[cite: 5] - Biblioteca para renderização de gráficos interativos e dinâmicos.

---

## 📁 Estrutura do Repositório

O projeto está organizado da seguinte forma dentro da pasta principal[cite: 5]:

```text
Relatório_gráfico/
│
└── dashboard-vendas/
    ├── index.html       # Página principal do dashboard
    ├── style.css        # Arquivo de estilização e layout
    ├── script.js        # Lógica de importação, filtros e gráficos
    └── vendas.xlsx      # Planilha de dados gerenciais em formato Excel
```
